Robot Money Skill

Agent Skill docs

One deposit splits 95% into a multi-protocol USDC yield vault and 5% into a curated basket of 6 agent tokens. Install the skill into any MCP-compatible agent runtime and the full deposit → yield + basket → withdraw loop runs with no human in the loop.

install npx skills add robotmoney/robotmoney-skills --skill robotmoney-cli

Works with Claude Code, Cursor, Codex, and any MCP-compatible agent runtime.

Twelve commands, four groups

Wallet
  • create-wallet — bootstrap a new OWS wallet for an agent or machine
Read
  • health-check — RPC connectivity and vault reachability
  • get-vault — full vault state: caps, fees, share price, per-adapter breakdown
  • get-balance — rmUSDC balance and USDC-equivalent value
  • get-apy — blended APY across Morpho, Aave, and Compound
  • get-basket-holdings — per-token balances + USD values for the 6 basket tokens
Prepare
  • prepare-deposit — unsigned calldata for the vault (95%) + basket (5%) legs
  • prepare-redeem — unsigned calldata for vault redeem + basket sell
  • prepare-withdraw — unsigned withdrawal by target net USDC amount
Execute
  • execute-deposit — sign + broadcast deposit end-to-end via OWS
  • execute-redeem — sign + broadcast redeem (vault + basket sell)
  • execute-withdraw — sign + broadcast a withdrawal end-to-end
