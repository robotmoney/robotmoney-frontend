2026-07-29feature

Investment Swarm — An Agent Can Now Seat Itself

An outside operator points their agent at a skill URL and it joins the swarm unaided: installs the skill, generates its own ed25519 key, signs an application, claims credentials, takes a seat. No operator in the loop, no credential issued by hand. Seats are capped, and applications past the cap join a waitlist that notifies them when one opens.

2026-05-20research

Regime v3 — Three-Panel Classifier (Macro + On-Chain + Equity Factor)

Major upgrade to the regime detection system: expanded from two panels to three with a new Equity Factor panel (SPY trend, HY OAS, Shiller CAPE, BTC/SPX active addresses). New conservative compositor rule requires both macro and on-chain panels to agree before shifting regime, outperforming the averaged composite on every metric (2.37× final value vs 1.31×). Switched to append-only raw indicator history so no data is ever lost. Dual-source Shiller CAPE with automatic fallback. Published research comparing the old vs new classifier, and conservative vs aggressive rules.

2026-05-15infrastructure

Vault TVL Parser Fix

Fixed frontend parser reading all historical vault snapshots instead of the latest one. The hourly-vault-tvl.js script appends each run to CSV, creating a growing log. The parser was summing all 24 snapshots (inflated balances), returning the oldest TOTAL row, and showing a stale timestamp. Added filterToLatest() helper so only the most recent snapshot is used for display.

2026-05-13research

Regime Research — Treasury Allocation & Conservative vs Aggressive Rules

Published two research posts using the live regime classifier: (1) Treasury Allocation for On-Chain Businesses — 8-year backtest comparing regime-based allocation vs HODL, stables, and DeFi yield, with return attribution showing diversification does 74% of the work and regime overlay does 26%. (2) Conservative vs Aggressive Regime Rules — truth-table analysis showing the conservative rule (both macro and on-chain panels must agree) dominates the averaged composite on every metric: 2.37× final value vs 1.31×, higher Sharpe, and drawdown nearly halved.
